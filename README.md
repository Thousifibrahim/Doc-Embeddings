# DOQ-AI-Agent

Chat with your PDFs! An AI-powered Streamlit app for smart document Q&A, employing a specialized information retrieval method (similar to RAG) with LangChain and Hugging Face.

## Overview

This repository contains the source code and supporting files for **DOQ-AI-Agent**.

## Getting started

```bash
git clone https://github.com/Thousifibrahim/DOQ-AI-Agent.git
cd DOQ-AI-Agent
```

Check the repository files for the project-specific entry point and setup requirements. Do not commit credentials, API keys, or private configuration files.
